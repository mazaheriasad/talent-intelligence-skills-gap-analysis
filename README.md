# Talent Intelligence & Skills Gap Analysis

## Project objective
Build an end-to-end Talent Intelligence portfolio project that identifies workforce skill gaps, evaluates employee readiness for target roles, and supports upskilling, internal mobility, recruiting, and workforce-planning decisions.

**Scenario:** NorthStar Digital Services is fictional. All workforce and skill data are synthetic.

## Phase 1 dataset
- `employee_master.csv` — 600 synthetic employees
- `employee_skills.csv` — employee-to-skill proficiency records
- `skills_taxonomy.csv` — canonical skills and NLP aliases
- `target_roles.csv` — eight target HR analytics / talent roles with synthetic job descriptions
- `role_skills.csv` — required skills, proficiency levels, importance weights, and mandatory flags
- `talent_intelligence_skills_gap_starter.xlsx` — formatted workbook containing all project inputs and documentation

## Planned analytics
1. Data-quality checks
2. Skills normalization
3. NLP-based skill extraction from job descriptions
4. Employee-role skill gap calculation
5. Weighted Role Readiness Score
6. Internal candidate ranking
7. Learning-priority recommendations
8. Power BI Talent Intelligence dashboard
9. Case study, GitHub documentation, LinkedIn and resume packaging

## Portfolio ethics
This project uses only synthetic people data. The outputs are designed for workforce planning and decision support, not automated employment decisions.
